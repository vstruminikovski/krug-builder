# Traffic-control survey (Prviot krug)

- `prviot_krug_map_2d.png`: overhead map of the route area, 2048 px, north up, 1 km square.
  Grid every 100 m from the centre. Base data © OpenStreetMap contributors (ODbL).
- `prviot_krug_survey_template.csv`: one row per sign, traffic light or marking.
- `prviot_krug.geojson`: the file the game loads. Fill it from the CSV (see `docs/MANUAL_SURVEY.md`).

Codes are the official Rulebook codes (Сл. весник 174/2020), e.g. II-2 stop, II-4 no entry,
III-2 one-way, III-3 priority road, V-1 stop line, V-4 zebra, VI-4.1 traffic light.
Only record what you have seen on site, with a GPS fix and a date.
